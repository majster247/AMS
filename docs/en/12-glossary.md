# Glossary

[PL](../12-glosariusz.md) | [EN](./12-glossary.md)

- **Ring 0**: privileged kernel mode.
- **Ring 3**: unprivileged userspace mode.
- **PMM/VMM**: physical/virtual memory managers.
- **CR3**: active page-table root register.
- **VFS**: virtual file abstraction.
- **ELF**: executable format used for userspace binaries.
- **syscall**: controlled userspace -> kernel transition.
- **iretq**: architectural return/transition instruction.
